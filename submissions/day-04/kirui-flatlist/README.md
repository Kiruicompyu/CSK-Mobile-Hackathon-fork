
# Day-04-Flatlist

## Contacts List Screen (React Native + FlatList)

I managed to implement a scrollable Contacts List screen using FlatList. Each contact is displayed as a reusable row component containing a profile image, contact name, and a short subtitle representing the user's role or occupation.

The contacts are rendered dynamically from an array of objects, demonstrating efficient list rendering with FlatList. Each item is styled with proper spacing, clean layout alignment, and circular avatar images to create a modern mobile UI.

Summary of the Features i employed..
* Scrollable contacts list using FlatList
* Reusable ContactItem component
* Profile avatar images for each contact
* Contact name and subtitle (role/occupation)
* Styled row layout with spacing between items
* Hidden scroll indicator for cleaner UI
